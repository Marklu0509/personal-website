Cloud Architecture & Serverless Pipeline

A cloud image-processing system that scales with demand — pairing always-on web servers with an event-driven serverless pipeline that processes uploads on demand without paying for idle capacity.

Project Info

Date2025
StatusPersonal project — infrastructure torn down; diagram on request
StackAWS (EC2, ALB, Auto Scaling, S3, EventBridge, Lambda, RDS, IAM, Secrets Manager, CloudWatch), CloudFormation, Python
Go back

A hybrid architecture pairs an auto-scaling EC2 + ALB tier with a serverless S3 → EventBridge → Lambda pipeline, so neither steady nor bursty load ever pays for idle compute — proven under ApacheBench load testing.

The whole stack is defined as code in CloudFormation, so it's reproducible and safe to change, and the data tier is hardened with private-subnet RDS, least-privilege IAM, and runtime secrets pulled from Secrets Manager.
