Cloud Architecture & Serverless Pipeline

A cloud image-processing system that scales with demand — pairing always-on web servers with an event-driven serverless pipeline that processes uploads on demand without paying for idle capacity.

Features

  • Uploaded images are processed automatically the moment they land.
  • Scales up under heavy traffic and back down when it's quiet — no manual intervention.

Why I built it

I wanted to design a cloud system that handles real, unpredictable traffic efficiently — and could be deployed and rebuilt safely from code rather than clicked together by hand.

Core technical

  • Absorbed bursty traffic without paying for idle compute using a hybrid AWS design (auto-scaling EC2 + ALB + serverless S3 → EventBridge → Lambda).
  • Proved automatic spike handling under ApacheBench load testing.
  • Made infrastructure reproducible and safe to change by defining the whole stack as code in CloudFormation.
  • Hardened security with private-subnet RDS, least-privilege IAM, and runtime secrets from Secrets Manager.
