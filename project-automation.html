Features

  • Processes a live event feed continuously, 24/7, without dropping or duplicating anything.
  • Recovers cleanly from restarts and crashes.
  • Surfaces incidents within seconds instead of hours.

Why I built it

I wanted to build and actually operate a genuinely reliable, always-on service — and learn production monitoring and incident response (SRE) hands-on rather than in theory.

Core technical

  • Guaranteed exactly-once processing across restarts with database-level idempotency, so no event is lost or double-counted.
  • Raised success rate from 71% to 99.7% by reverse-engineering a hidden upstream API rule from structured logs.
  • Cut incident detection from hours to under 90 seconds with Prometheus/Grafana monitoring-as-code that fires even on a crash.
