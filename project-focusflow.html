FocusFlow, A Pomodoro Clock

A full-stack focus-timer platform that helps people work in structured sessions and track their productivity over time — available as both a web app and a browser extension.

Features

  • Run focused work sessions with a Pomodoro-style timer that keeps perfect time — even when it's running in the background.
  • Use it your way: a full web app or a lightweight browser extension, always in sync.
  • Track your productivity over time with a daily focus history.
  • One account, one source of truth — your sessions follow you across devices.

Why I built it

Most browser timers drift or reset the moment you switch tabs, so I wanted a focus tool I could actually trust. I also used it to build a real multi-client, polyglot system end to end.

Core technical

  • Kept the timer accurate in the background by persisting an end-timestamp in a Chrome MV3 extension, surviving service-worker sleep.
  • Served both a Next.js web app and the extension from one API-first NestJS backend, so new clients need zero backend change.
  • Split read-heavy analytics into a separate Go service so each part scales independently.
  • Automated one-push deploys with GitHub Actions so even a small server ships reliably.
