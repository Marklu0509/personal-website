FocusFlow, A Pomodoro Clock

Pomodoro keeps me focused — but the usual screen-locking apps always got in my way. So I built one that plays your own music and blocks just the sites that distract you.

Features

  • Break work into focused sessions with a Pomodoro-style timer that keeps perfect time — even while it runs in the background.
  • Organise work into separate tasks, each with a target number of sessions and its own focus mode.
  • Tune every session: custom lengths, end-of-session alarms and ambient sound, and your own YouTube music.
  • Track your momentum with focus analytics — daily goals, weekly trends, and your best days.
  • Use it as a web app or a Chrome extension that runs in the background and blocks distracting sites.

Why I built it

Most browser timers drift or reset the moment you switch tabs, so I wanted a focus tool I could actually trust. I also used it to build a real multi-client, polyglot system end to end.

Core technical

  • Kept the timer accurate in the background by persisting an end-timestamp in a Chrome MV3 extension, surviving service-worker sleep.
  • Served both a Next.js web app and the extension from one API-first NestJS backend, so new clients need zero backend change.
  • Split read-heavy analytics into a separate Go service so each part scales independently.
  • Automated one-push deploys with GitHub Actions so even a small server ships reliably.
