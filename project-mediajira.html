MediaJira Campaign Workflow

RoleSoftware Engineer Intern
Year2024
StackReact, Django, Docker
Context
A media platform where teams plan and track advertising campaigns.
My focus
Full-stack feature delivery and developer tooling.
Team
Small agile squad, weekly reviews.

I joined the campaign workflow team to help ship features that connected the planning interface to the underlying data model. Most of my work sat across the full stack — designing API endpoints, wiring them into the React interface, and keeping the data flow easy to follow.

Alongside features, I invested in the parts of the codebase that make change cheaper: containerising the dev environment so setup took minutes instead of an afternoon, and adding CI checks and integration tests around the flows most likely to break.

The lesson I took away was about scope. The most useful thing I did some weeks wasn't a feature at all — it was removing a step, a config, or a manual process that everyone had quietly accepted.
