Vision-Language Model Fine-Tuning & Evaluation

A research pipeline that fine-tunes a vision-language model to describe images faithfully, paired with an automated "LLM-as-judge" system that measures how trustworthy those descriptions really are.

Features

  • Produces faithful, image-grounded descriptions instead of fluent-but-hallucinated ones.
  • Automatically scores how trustworthy any model's outputs are, with a reusable evaluation benchmark.

Why I built it

Vision-language models sound convincing even when they're wrong, and measuring that is expensive and subjective. We set out to make faithfulness both achievable (via fine-tuning) and measurable (via an automated judge).

Core technical

  • LoRA fine-tuned a vision-language model that beat all three baselines — including a 2025 SOTA model — on every faithfulness metric.
  • Built ArtcomBench, an LLM-as-judge pipeline that breaks each output into checkable claims and verifies them.
  • Kept the evaluation trustworthy by validating 3,500 AI-generated labels against human raters (ICC 0.82).
