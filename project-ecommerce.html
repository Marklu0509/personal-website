Distributed E-Commerce Microservices

A distributed e-commerce backend where independent services (store, bank, delivery, email) coordinate a single order reliably over messaging, staying consistent even when individual services fail.

Project Info

Date2025
TeamTeam project — 4 developers
StackJava 17, Spring Boot, Spring Data JPA / Hibernate, PostgreSQL, RabbitMQ, React, TypeScript
View on GitHub Go back

Four services communicate purely over RabbitMQ, so one slow service can't block the rest. A transactional outbox guarantees zero message loss through broker outages, and idempotent handlers prevent customers being double-charged.

The Saga pattern keeps orders consistent across services by auto-rolling-back stock and payment on failure, while row-level locks stop stock overselling without throttling store throughput.
